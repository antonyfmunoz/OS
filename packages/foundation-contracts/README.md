# Foundation Contracts

Machine-readable shared foundation contracts for UMH projections.

Canonical source lives in:

- `schemas/` JSON Schema 2020-12 files
- `registry/` command, event, compatibility, and alias metadata
- `fixtures/` conformance examples

Generated bindings live in:

- `generated/python/`
- `generated/typescript/`

Generated files are derivative. Do not hand-edit them.
