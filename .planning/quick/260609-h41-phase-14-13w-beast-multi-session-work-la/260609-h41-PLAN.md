    **app_resolver.py** (~150 lines):
    - `AppTarget` dataclass — app_key, display_name, is_native (bool), process_name, launch_cmd (str|None for native), open_url (str|None for web), browser (str, default "chrome"), domain
    - `_NATIVE_APP_KEYS` — frozenset of PLATFORM_PROCESS_MAP keys that have real desktop processes (spotify, discord, slack, code, cursor, obsidian, notion, steam, explorer, windowsterminal, powershell, github, claude, docker). Exclude "chrome" itself from native (it's the browser).
    - `classify_app_vs_website(text: str) -> str` — returns "native_app" | "website" | "unknown":
      1. Strip verb prefixes ("open ", "launch ", "pull up ", "search for ")
      2. Check remainder against _NATIVE_APP_KEYS (import from environment_mapping_engine_v1 PLATFORM_PROCESS_MAP at runtime)
      3. If found in native keys -> "native_app"
      4. If text contains "search", "browse", "look up", "find on", "go to" -> "website"
      5. If remainder looks like a domain (contains dot) -> "website"
      6. Default: "unknown"
    - `resolve_app_target(name: str) -> AppTarget`:
      1. Normalize name (lowercase, strip)
      2. Look up in PLATFORM_PROCESS_MAP
      3. If found and in _NATIVE_APP_KEYS: return AppTarget(is_native=True, process_name from map, launch_cmd=f"start {process}", open_url=None, browser="")
      4. If found but NOT native (chrome itself): return AppTarget with the chrome process details but open_url set
      5. If NOT found in map: treat as website, return AppTarget(is_native=False, browser="chrome", open_url=f"https://{name}.com" if name.isalpha() else None)
      6. CHROME-FIRST RULE: browser field is ALWAYS "chrome" for web targets. Never edge. Never explorer. Never default OS browser. This is the E workcell.
    - `_SEARCH_PATTERNS` — list of prefixes that indicate web search intent ("search for ", "look up ", "find ", "google ")
    - `resolve_search_url(text: str) -> str | None` — if search pattern matched, return f"https://www.google.com/search?q={url_encoded_query}"

    **loop_engine.py** (~170 lines):
    - `LoopStatus(str, Enum)` — pending, running, verified, failed, abandoned
    - `LoopContract` dataclass — contract_id (auto uuid), task_description, end_state_description, max_iterations (default 5), current_iteration (0), status (LoopStatus.pending), started_at, completed_at, evidence_log (list[str])
    - `VerifyResult` dataclass — verified (bool), reason (str), evidence_summary (str), iteration (int)
    - `EndStateVerifier`:
      - `verify(contract: LoopContract, evidence: dict) -> VerifyResult` — deterministic verification:
        1. If evidence.get("screenshot_taken") and contract end_state mentions "visible" -> check evidence has non-empty image
        2. If evidence.get("process_running") and contract end_state mentions "open" or "running" -> check process name matches
        3. If evidence.get("url_loaded") and contract end_state mentions "page" or "loaded" -> check URL is non-empty
        4. If evidence.get("file_exists") -> check path non-empty
        5. Generic: if evidence.get("completed") is True -> verified
        6. If none matched -> not verified, reason="no matching verification strategy"
      - Deterministic-first: no LLM, pattern matching on end_state_description keywords
    - `LoopProgressReport` dataclass — contract_id, iteration, status, evidence_snapshot (dict), timestamp, lane_id
    - `advance_loop(contract: LoopContract, evidence: dict) -> tuple[LoopContract, VerifyResult]`:
      1. Increment current_iteration
      2. Run EndStateVerifier.verify()
      3. If verified -> set status to verified, set completed_at
      4. If current_iteration >= max_iterations -> set status to failed
      5. Append evidence summary to evidence_log
      6. Return updated contract and verify result
    - `create_loop_report(contract: LoopContract, lane_id: str) -> LoopProgressReport` — snapshot for cockpit display

    All three files: type hints on all public functions. Docstrings on all classes and public methods. No LLM calls. Python 3.11 compatible.
